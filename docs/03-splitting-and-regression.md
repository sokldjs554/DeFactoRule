# 질의–회답 분할과 서식 회귀 테스트

두 가지를 했다. 하나는 계획대로 되지 않았고, 그 실패에서 나온 교훈이 다른 하나를
만들었다.

---

## 1. 질의–회답 분할 — 계획보다 훨씬 작았다

### 착수 근거가 틀렸다

앞선 보고에서 "복수 질의 사례 30건 이상, 쪼개면 유효 학습 단위가 크게 늘어난다"고
적었다. **틀렸다.** 그 숫자는 거친 정규식이 만든 과대추정이었다.

순번 문자(①②③, ➀➁➂, ❶❷❸, ⑴⑵⑶ 및 HWP 사설영역 글리프)를 정규화해 다시 세었다.

| 항목 | 실측 |
|---|---|
| 질의요지에 순번 2개 이상 | 10건 |
| 회답에 순번 2개 이상 | 10건 |
| **양쪽 순번이 맞아 짝을 지을 수 있는 사례** | **4건** |

앞서 "혼재 152건"이라 보고한 것도 정확하지 않았다. 실제 혼재(긍정·부정 표현이 함께
등장)는 24건이고 나머지 128건은 **불명**(정규식이 아무 판정도 못 함)이다.
그리고 그 혼재 24건 중 복수 질의 표지를 가진 사례는 **0%**였다.
즉 혼재는 복수 질의 때문이 아니라 문장 자체가 복잡해서 생긴 것이다.

### 회답 단독 분할은 적극적으로 해로웠다

처음 구현은 "회답에만 순번이 있으면 회답만 자른다"는 폴백을 두었고, 그것으로 81쌍이
생겼다. 표본을 열어 보니 **전부 오분할**이었다.

```
① 의결권 있는 발행주식 10% 이상을 소유하거나
② 혼자서 또는 다른 주주와 합의·계약 등으로 대표이사 또는 이사의 과반수를
   선임하는 등의 사정이 없는 이상 금융회사의 대주주에 해당하지 않는 것으로
   판단됩니다.
```

이것은 **한 문장**이다. 순번마다 쪼개면 결론절("해당하지 않는 것으로 판단됩니다")이
통째로 ②에 딸려가고, ①은 결론 없는 요건 조각이 된다. 다른 사례도 마찬가지였다 —
`①주식소유비율이 제1위에 해당할 것 / ②주식의 분산도로 보아…`는 요건 열거이지
질의 구분이 아니다.

> **이 문서군에서 ①②는 압도적으로 질의 구분이 아니라 요건·조건을 열거하는 표지다.**

역설적이지만 이 발견은 프로젝트에 유리하다. 그 요건 열거야말로 이 프로젝트가 찾으려는
**판단 기준 그 자체**다. 쪼개서 흩을 대상이 아니라 구조를 보존하고 추출할 대상이다.
회답 단독 분할을 제거하고, 대신 `has_enumeration` 플래그로 표시만 남겼다.

### 결과

| | 값 |
|---|---|
| 사례 | 433 |
| 질의–회답 쌍 | **438** (+5) |
| `single` | 429 |
| `paired` | 9 (4개 사례) |

`paired` 9쌍은 전수 검토했고 모두 정상이다. 예: 일련번호 230354는 프랜차이즈 카드결제
관련 3개 질의가 각각 대응하는 회답을 갖는다.

건수 이득은 미미하다. 그래도 유지하는 이유는 **라벨 오염 방지**다. 쪼개지 않으면 한 행에
서로 반대되는 결론이 섞인다.

## 2. 서식 회귀 테스트 — 2024년 사건의 재발 방지

### 왜 필요한가

## 두 번째 오분할 — 순번 교집합

회답 단독 분할을 없앤 뒤에도 같은 뿌리의 실수가 하나 남아 있었다. 질의와 회답
양쪽에 순번이 있으면 **교집합**이 2개 이상일 때 짝을 지어 잘랐다.

실제 사례(210465):

```
질의  카지노사업자가 … "➊보관 혹은 ➋게임참여"를 목적으로 … ➌'보관증'을 영수하고
      칩을 지급하는 행위, ➍현금을 영수하고 '바우처'를 지급하는 행위 및
      ➎'바우처'를 영수하고 현금을 지급하는 행위가 … 보고 대상이 되는지 여부

회답  󰊱 … ➌'현금을 영수하고 발행·지급해준 보관증'을 영수하고 칩을 지급하는 행위는
         … 보고 대상이 될 수 있을 것입니다.
      󰊲 … "➊보관 혹은 ➋게임참여"를 목적으로 … 및 ➍ 및 ➎ … 대상이 아니라고 판단됩니다.
```

질의의 ➊~➎ 는 **다섯 개 질문이 아니라 한 질문 안의 행위 열거**다. 회답의 󰊱󰊲 는
그것을 두 묶음으로 나눈 답변이다. 그런데 교집합 {1,2} 로 짝을 지어

- 질의① "보관 혹은 게임참여" ↔ 회답① "➌현금을 영수하고 …" 를 붙였고
- 질의 ➌➍➎ 는 **경고도 없이 사라졌다**

순번 집합이 **정확히 같을 때만** 자르도록 고쳤다. 어긋나면 자르지 않고
`mark_mismatch` 경고를 남긴다. 코퍼스 전체에서 2건이 이렇게 잘리고 있었고,
짝 분할이 유지되는 18건은 순번 집합이 정확히 같다. 쌍 1,124 → **1,122**.

교훈은 EX-12 와 같다 — **순번은 질의 구분일 수도 있고 열거일 수도 있다.**
양쪽이 정확히 대응할 때만 구분이라고 믿을 수 있다.

2024년판 사례집을 넣은 순간 결론 검출률이 **97% → 38%**로 떨어졌다. 그런데
**파싱은 "성공"했다.** 파서는 서식을 못 읽어도 예외를 내지 않고 빈 값을 남기기
때문이다. 건수만 보면 정상이었다.

이런 실패는 조용하다. 연도를 추가할 때마다 같은 일이 일어날 수 있고, 알아채지 못한 채
학습으로 넘어가면 라벨의 60%가 결측인 데이터로 모델을 만들게 된다.

### 구조

```
scripts/format_inventory.py       서식 지문 생성
tests/regression/baseline.json    고정된 기준선 (커밋됨)
tests/regression/
  test_casebook_formats.py        원본 PDF 대상 — 로컬에서만 실행
  test_processed_data.py          커밋된 파싱 결과 대상 — CI 에서 실행
```

원본 PDF 는 저장소에 커밋하지 않으므로, 서식 지문 테스트는 CI 에서 자동으로 건너뛴다.
대신 파싱 결과는 커밋되어 있어 그 불변조건을 CI 가 검사한다.

### 기준선에 고정된 체크박스 서식 7종 + 1

```
☑비조치□조치□기타
þ비조치□조치□기타          Wingdings 체크박스
√□비조치□조치□기타         체크가 상자 앞
□비조치√□조치□기타
□비조치□조치√□기타
□비조치☑조치□기타
□비조치□조치☑기타
(헤더에 체크박스 없음)
```

### 테스트가 실제로 잡는지 검증했다

파서의 결론 인식을 2024년 이전 상태(`☑`만 인식)로 되돌리고 실행했다.

```
FAILED test_extraction_rates_hold[decision_rate]
  검출률 미달:
    2024년 비조치의견서 사례집(금융감독원).pdf: decision_rate=40.51% < 90%
```

정확히 그 사건을 재현해 잡았다. 파서를 복원하니 17개 테스트 전부 통과한다.

## 3. 남은 것

- **띄어쓰기 소실 45건** — 비조치의견서 PDF 특성. 토크나이저 투입 전 복원 필요
- **불명 128건** — 회답의 결론을 정규식으로 판정할 수 없다. 이것이 LLM 이 맡을 자리이며,
  파서에 규칙으로 넣지 않은 이유이기도 하다
- **코퍼스 433건** — 게이트 800건까지 2개 연도분 부족

## 4. 회귀 테스트가 실제로 일을 했다 — 2022·2023년판 투입

기준선을 만든 직후 2022·2023년 사례집이 들어왔다. 테스트를 돌리자 세 개가 실패했다.

```
FAILED test_no_unknown_checkbox_format
  처음 보는 체크박스 서식입니다:
    ■비조치□조치■기타
    ■비조치□조치□기타
    □비조치■조치□기타
    □비조치□조치■기타

FAILED test_no_unknown_check_glyph
  처음 보는 체크 문자: ['■']

FAILED test_new_sources_are_declared
  기준선에 없는 자료입니다: (4건)
```

**설계 의도 그대로 동작했다.** 이 테스트가 없었다면 `■`가 새 서식이라는 사실을
알아채지 못했을 것이다.

그리고 그중 하나가 **이중 체크**였다.

```
비조치의견서 (■비조치 □조치 ■기타)
(일련번호 220029)
```

한국씨티은행 이용자보호계획 관련 건으로, 요청 사항 일부는 비조치, 일부는 기타로
회신된 것이다. 첫 매치만 취하던 기존 구현은 이걸 조용히 "비조치"로 만들어 버린다.
941건 중 1건이지만, 이런 오염은 발견되지 않으면 영원히 남는다.

`decision`(단일 라벨)과 `decisions`(체크된 것 전부)를 분리하고, 복수 체크는
단일 라벨을 비운 뒤 `multi_decision` 으로 표시하도록 바꿨다.

### 연도별 체크박스 서식 — 2024년판이 유독 난장판이다

| 연도 | 서식 종류 | 내역 |
|---|---|---|
| 2022 | 2종 + 이중체크 | `■` 계열 |
| 2023 | 1종 | `☑` 계열 |
| **2024** | **5종** | `☑`, Wingdings `þ`, `√□`(상자 앞 체크) 혼재 |
| 2025 | 1종 | `☑` 계열 |

같은 발간 기관이 해마다 다른 조판 도구를 쓴 흔적으로 보인다. 특히 2024년판은
한 권 안에서 서식이 섞여 있어, **표본 몇 건만 보고 파서를 짜면 반드시 실패한다.**

기준선에 고정된 체크박스 서식은 이제 11종 + `(헤더에 체크박스 없음)`이다.

### 함께 드러난 두 가지 결함

**업권 오탐.** 구분 페이지 판정의 길이 상한이 느슨해 본문 첫 페이지가 업권으로
잡혔다. `기초서류에서정하는방법에따른경우`가 업권으로 집계된 것이 그 흔적이다.
상한을 90자로 조이고 이름 패턴을 좁혔다.

**업권 전량 미분류(50건).** 위 수정의 부작용으로 2022년 비조치의견서판의 구분
페이지를 놓쳤다. 그 판은 `공 통\n2022년\n비조치의견서 사례집` 형태로,
**이름 뒤에 연도**가 오고 제목이 자간을 벌려 조판돼 `공 통`처럼 글자 사이에 공백이
들어간다. 네 번째 패턴을 추가해 미분류 0건이 됐다.

구분 페이지 서식은 현재 네 종류다.

```
공통\n1\n법령해석 회신문 사례집[2025년도]      이름 → 번호
공 통\n2022년\n비조치의견서 사례집             이름 → 연도 (자간 벌림)
1. 공통                                        번호 → 이름
•∙<장식>∙•\n금융정책 일반                      소분류
```

여기에 `상호저축은행`/`상호저축은행업` 같은 표기 흔들림을 별칭 표로 통일했다.
