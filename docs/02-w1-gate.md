# W1 게이트 — Track A 코퍼스 실측 결과

**판정: 미달.** 2025년 사례집 단독으로는 게이트를 통과하지 못한다. 이전 연도 사례집 확보가 필요하다.

| 기준 (Phase −1 보고서 §10-6) | 목표 | 실측 | 판정 |
|---|---|---|---|
| Track A 파싱 성공 건수 | ≥ 800 | **213** | ❌ |
| Track B 부가조건 구조화 | ≥ 150 | 미착수 | — |

미달이지만 프로젝트를 접을 상황은 아니다. 사례집은 **연간 발간물**이므로 연도를 늘리면 선형으로 확보된다. 2025년 한 해가 213건이면 10개 연도로 2,000건 규모가 된다.

### 결론 라벨

**비조치의견서** — 문서에 체크박스로 박혀 있어 라벨링이 불필요하다.

| 결론 | 건수 |
|---|---|
| 비조치 | 49 |
| 조치 | 2 |
| 기타 | 1 |
| 미확인 | 2 |

**49 : 2 : 1.** Phase −1 보고서에서 실패 케이스로 적어둔 "클래스 불균형 — 대부분 승인"이
그대로 나타났다. 비조치의견서 단독으로는 이진 분류 학습이 불가능하다.

**법령해석 회신문** — 회답 본문에서 결론을 판정해야 한다. 문서에 라벨이 없다.

회답 본문 확보 154/159. 클래스 균형이 있는지만 보기 위한 **어림 스캔** 결과:

| 어림 분류 | 건수 |
|---|---|
| 부정 (해당하지 않음·불가) | 39 |
| 긍정 (해당함·가능) | 30 |
| 혼재/불명 | 85 |

> 이 숫자는 정규식 휴리스틱이며 **라벨이 아니다.** 게이트 판정을 위해 클래스 균형 여부만
> 확인한 것이다. 혼재 85건이 많은 이유는 한 사례가 ①②③ 복수 질의를 담는 경우가 흔하기
> 때문으로, 실제 라벨링은 질의 단위로 쪼개야 한다.
>
> 회답의 함의 판정을 파서에 규칙으로 넣지 않은 것은 의도적이다. 그 판정이 바로 이
> 프로젝트가 측정하려는 대상이므로, 파싱 단계에서 규칙으로 확정해 버리면 이후 단계의
> 성능을 측정할 수 없게 된다.

**결론: 학습 신호는 법령해석 회신문 쪽에 있다.** 비조치의견서는 라벨이 확정적이라는
장점이 있으나 분포가 무너져 있어, 보조 코퍼스 또는 부가조건(예외 문구) 추출용으로 쓴다.

## 3. 파서 품질

| 경고 | 건수 | 비고 |
|---|---|---|
| `spacing_lost` | 23 | 비조치의견서 PDF는 한글 사이 공백이 소실된 채 추출된다 |
| `missing_field:이유` | 8 | 법령해석 서식 변형 |
| `missing_field:회답` | 5 | 〃 |
| `missing_field:질의요지` | 4 | 〃 |
| `missing_field:판단이유` | 2 | 비조치 서식 변형 |
| `missing_field:요청대상행위` | 2 | 〃 |
| `missing_field:판단` | 2 | 〃 |
| `missing_decision` | 2 | 체크박스 미검출 |
| `missing_serial` | 1 | 일련번호 미표기 |

항목 추출 실패율은 법령해석 약 11%, 비조치 약 11%다.

### 개발 중 잡은 결함

1. **`판단이유` 100% 누락** — 항목명을 짧은 것부터 매칭해 `판단`이 `판단이유`를 삼켰다.
   긴 이름·넓은 줄 span 우선으로 바꿔 54건 → 2건.
2. **업권 전량 미분류** — 구분 페이지 서식이 세 종류였다.
   금융위 대분류는 `공통\n1`(이름→번호), 소분류는 `•∙…∙•\n금융정책 일반`,
   금감원은 `1. 공통`(번호→이름). 세 패턴을 모두 처리해 159건 미분류 → 0건.
3. **중복 일련번호 16종으로 오집계** — 두 문서의 일련번호를 한 네임스페이스에서 셌다.
   문서별로 분리하니 실제 중복은 법령해석 `230094` 1건(3회 출현)뿐이었다.

### 남은 문제

- **띄어쓰기 소실** (`spacing_lost` 23건). 비조치의견서 PDF의 글자 배치 특성이다.
  토크나이저에 그대로 넣으면 안 된다. 한국어 띄어쓰기 복원이 필요하며,
  복원 품질 자체가 하나의 실험 대상이 된다.
- **복수 질의 사례**. 한 사례에 ①②③가 들어 있으면 질의–회답 쌍으로 쪼개야 한다.
  현재는 사례 단위로만 자른다.

## 4. 다음에 필요한 것

1. **이전 연도 사례집** — 게이트 통과의 유일한 경로. 2015~2024년 비조치의견서·법령해석
   사례집을 확보하면 1,000~2,000건 규모가 된다.
2. **Track B 착수** — 혁신금융서비스 지정 보도자료. Track A가 목표에 못 미치면 Track B가
   보완 경로가 된다.
3. **질의 단위 분할** — 복수 질의 사례를 쪼개면 유효 학습 단위가 213건보다 늘어난다.

## 5. 재현 방법

```bash
pip install -r requirements-collect.txt

python scripts/parse_casebook.py --input data/raw/casebooks --output data/processed
```
