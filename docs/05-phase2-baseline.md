# Phase 2 — 결론 판정 baseline

Phase 1 은 1,095 사례 / 1,124 질의–회답 쌍을 확보했다. Phase 2 는 그 회답이 **어떤
결론인가**를 판정하는 단계다. 이 판정이 이후 규칙 학습의 입력이 된다.

## 라벨 체계

| 라벨 | 뜻 |
|---|---|
| 긍정 | 질의한 행위·해석이 가능하다 / 해당한다 |
| 부정 | 불가하다 / 해당하지 않는다 |
| 조건부 | 일정 요건을 갖추면 가능하다 (요건이 회답에 명시되어야 한다) |
| **판단유보** | 개별 사실관계에 따라 다르다 / 결론을 내리지 않았다 |

`판단유보` 를 둔 것은 편의가 아니다. 규제당국은 "구체적 사실관계에 따라 달라진다"는
회답을 실제로 자주 낸다. 그것을 긍정이나 부정으로 욱여넣으면 데이터가 거짓이 되고,
나중에 Agent 가 **"언제 판단하면 안 되는가"**를 배울 근거도 사라진다.

비조치의견서는 결론이 체크박스로 문서에 박혀 있어 라벨이 공짜다(184:49:22).
법령해석 회신문은 라벨이 없고, **그 판정이 바로 이 프로젝트가 측정하려는 대상**이라
파서 단계에서 규칙으로 확정하지 않았다.

## 규칙 baseline — 진지하게 만들고, 정직하게 진다

허수아비 baseline 을 세워 놓고 이기는 것은 아무것도 증명하지 못한다. 결론절 표현을
네 갈래(유보·조건부·부정·긍정)로 나눠 정규식을 만들고, 유보를 최우선으로 두고,
부정과 긍정이 함께 걸리면 뒤에 나온 쪽을 택하게 했다.

결과 (법령해석 864쌍):

| | 건수 | 비율 |
|---|---|---|
| **규칙이 판정한 것** | 355 | **41.1%** |
| 미분류 (규칙이 아무것도 못 잡음) | 509 | 58.9% |

판정한 355건의 내역은 긍정 188 · 부정 101 · 판단유보 66 · 조건부 0이다.

### 미분류를 판단유보로 뭉치지 않는다

처음 구현은 규칙이 아무것도 못 잡으면 `판단유보` 로 적었다. 그러면 분포가
판단유보 66.6% 로 나오는데, 그 안에는 **"당국이 유보한 것"과 "규칙이 못 읽은 것"이
섞여 있다.** 두 가지는 평가에서 전혀 다르게 다뤄야 한다.

`미분류` 를 별도 값으로 분리했다. baseline 의 정직한 성적표는 한 숫자가 아니라
**커버리지 41.1% + 판정한 것의 정확도** 두 숫자다.

이 59% 가 LLM 이 맡을 자리이며, 그 근거가 이제 수치로 남아 있다.

## LLM 분류기 설계

```
LLM     회답 자연어 → 결론 라벨 + 판정 근거가 된 원문 구절 인용
코드    라벨 유효성 · 인용 구절이 원문에 실재하는지 대조 · 집계
```

**인용 구절을 원문과 글자 단위로 대조하는 것이 핵심이다.** 모델이 그럴듯한 요약을
지어내면 대조에서 걸린다. 이 검증 없이 라벨만 받으면 환각을 발견할 방법이 없다.
근거를 찾지 못하면 `판단유보` + 빈 인용을 반환하도록 지시한다 — 추측하지 않는 것이
틀린 답보다 낫다.

모델은 `claude-opus-5`, adaptive thinking, structured outputs 로 라벨 스키마를 강제한다.

> **현 환경에서는 실행할 수 없다.** `ANTHROPIC_API_KEY` 도 `ant` CLI 도 없다.
> 키가 설정되면 `python scripts/classify_llm.py` 로 바로 돌아간다.

## Gold set

성능을 말하려면 정답이 있어야 한다. 122건을 **층화 추출**했다.

| 연도 | 건수 | | 업권 | 건수 |
|---|---|---|---|---|
| 2021 | 23 | | 공통 | 45 |
| 2022 | 27 | | 자본시장 | 30 |
| 2023 | 27 | | 금융혁신 | 12 |
| 2024 | 21 | | 보험 · 은행 | 각 9 |
| 2025 | 24 | | 중소금융 · 디지털금융 | 각 8 |

무작위로 뽑으면 다수 업권이 표본을 독식해 소수 업권 성능을 영영 모르게 된다.
연도도 섞었다 — 서식과 문체가 해마다 달랐다는 것을 이미 확인했기 때문이다.
난수를 쓰지 않아 몇 번을 돌려도 같은 표본이 나오고, 라벨링 작업이 헛돌지 않는다.

`data/eval/gold_unlabeled.jsonl` 의 `label` 을 채우면 된다. 지침은
`data/eval/LABELING.md` 에 함께 생성된다.

## 평가 하네스

baseline 과 LLM 을 **같은 하네스**로 잰다. 서로 다른 스크립트로 잰 숫자를 나란히
놓고 비교하면 그 비교는 믿을 수 없다.

측정 항목: 커버리지 · 판정한 것의 정확도 · 라벨별 P/R/F1 · 매크로 F1 · 혼동 쌍 ·
인용 미대조율. 클래스 불균형이 심하므로 매크로 F1 을 본다.
