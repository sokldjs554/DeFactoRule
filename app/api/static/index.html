02

신뢰도 기준 테스트

최소 신뢰도를 바꿔 결과가 어떻게 달라지는지 확인할 수 있습니다. 설정한 기준보다 신뢰도가 낮으면 결과 대신 ‘판단 보류’가 표시됩니다.

판정 결과가 여기에 표시됩니다.
03

근거 검색

요청과 닮은 선례를 찾되, 요청보다 나중에 나온 사례는 후보에서 뺍니다. 찾은 선례는 출처 문서와 쪽수, 유사도, 그때의 결론을 함께 표시합니다. 검색만 하므로 외부 API를 부르지 않습니다.

사례를 불러오는 중입니다.

04

업권별 라벨 분포

업권마다 조치·비조치 비율이 달라서 정확도만 보면 성능을 잘못 해석할 수 있습니다. 이를 확인할 수 있도록 dev 세트의 업권별 분포를 함께 표시했습니다. 표본이 5건 미만인 업권은 전체 분포를 사용합니다.

05

실패 사례 관리

개발 중 발견한 오류와 이를 다시 확인하는 테스트 목록입니다. 수정한 문제가 다시 발생하면 ‘재발’로 표시됩니다. 실험 기록이나 방법론 결정처럼 다시 발생할 코드가 없는 사례, 그리고 다른 테스트가 이미 덮고 있는 사례는 개별 검사를 두지 않습니다.

화면의 지표는 저장소에 저장된 평가 결과를 사용합니다. 페이지를 열 때 모델을 새로 실행하지 않습니다.
